# SkillPath v0.1 — How to use

SkillPath is a learning-path tracker. Data is saved in your browser (localStorage); nothing is sent to a server.

1. **Create a path:** type a name (e.g. "Learn JavaScript") and click **Add path**.
2. **Add steps:** type a step in the box under the path and press Enter or **Add step**.
3. **Check off steps:** tick the checkbox. The completion date is recorded.
4. **Reorder / remove:** use ↑ ↓ to move a step, ✕ to remove it. **Delete** removes the whole path.
5. **Progress:** each path shows a progress bar, done/total count and the next step.
6. **Backup:** **Export JSON** downloads all paths; **Import JSON** restores them (replaces current data).

Limits: browser-only storage, no accounts or sync. Not linked from the main site.
